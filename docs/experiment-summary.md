**测试卷全量遍历参照**：993,816 个文件，耗时 **84.878 s**（不施加扩展名过滤）。

**覆盖差异**：38,916（遍历）vs 29,516（索引），比例 1.32 倍。索引未覆盖部分系统保留目录与隐藏项。
→ 不影响量级结论，但要求完备性的场景需注意。

## 七、复现命令

```bash
ES="${ES_EXE:-es.exe}"

# 索引规模
"$ES" -get-result-count "*" | iconv -f GBK -t UTF-8

# 单次查询（计时）
time "$ES" -n 20 "*.md" -path "<test-volume>/" | iconv -f GBK -t UTF-8

# 输出规模
"$ES" -n 20 "*.md" -path "<test-volume>/" | iconv -f GBK -t UTF-8 | awk '{t+=length($0);n++} END {print n, t}'
```

```powershell
# 递归遍历基线（测试卷）
$sw = [System.Diagnostics.Stopwatch]::StartNew()
$m = Get-ChildItem -LiteralPath "<test-volume>\" -Recurse -File -Force -ErrorAction SilentlyContinue | Measure-Object
$sw.Stop(); "files=$($m.Count) elapsed=$($sw.Elapsed.TotalSeconds)"
```

## 八、踩坑记录（采集过程本身）

1. **Python `os.scandir` 遍历系统卷跑 6 分 25 秒未完成，被手动终止**。原因：系统卷含 163.6 万条目且系统目录（WinSxS 等）元数据开销大。改用 PowerShell `Get-ChildItem` 后测试卷 99.4 万文件 84.9 秒完成。
2. **PowerShell 工具禁止调用 `cmd.exe`**（安全策略），故 `dir /s /b` 方案不可用。
3. **后台任务的 stdout 被全缓冲**，实时看不到进度；改用 PowerShell 前台/后台并读取最终输出。
4. **`awk length()` 按字节计**，中文路径会虚高；用 Python `len()` 复核后确认本机路径以 ASCII 为主，两者一致（112.8 / 123.4）。
